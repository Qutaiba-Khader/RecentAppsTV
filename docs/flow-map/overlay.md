## Mode combinations

Scene (LOADING, OVERLAY, EMPTY, SHIZUKU) × Kill All shown/hidden × pins (none / left / right, running or not, only pins) × focused item (⚙ tile, Kill All, task, pin, past the end) × transient guards (peek up/down, flying for dismiss/exception, killing, busy, selecting, pressing, menu, long-press, closing). Guards × keys: P-OVL-20/23/27/39/44, gates G-OK / G-INPUT / G-HOLD / G-DISMISS / G-ROW. Menu rows × release: P-OVL-31…38, P-OVL-46. Real-remote hold (repeats every ~50 ms, 550 ms timer): P-OVL-48, 49; ⚙ Settings button (above Kill All, or in the row without Kill All): P-OVL-50…52.
